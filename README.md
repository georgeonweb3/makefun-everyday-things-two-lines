Two lines that explain one everyday thing to a 10-year-old with a vivid analogy, then say honestly what that analogy maps and what it leaves out. The program is deterministic, stdlib only, no network: it writes the two lines to `entry.txt`, re-reads it to verify byte-for-byte equality, and prints exactly the two lines.

## Run it

```sh
python3 main.py
```
